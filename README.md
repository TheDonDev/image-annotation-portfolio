# Image Annotation & Quality Assurance Demonstration

**Computer Vision | Object Detection | Image Labelling | Data Quality**

## Project Overview

This project demonstrates a practical image annotation and quality assurance workflow using Python and OpenCV.

It uses a Nairobi street-scene photograph to demonstrate object identification, bounding-box annotation, structured data storage and automated annotation validation.

This is an independent portfolio demonstration.

## Objectives

- Identify and classify objects in an image.
- Create bounding boxes around visible objects.
- Store annotations in structured JSON format.
- Validate annotation coordinates and categories.
- Document annotation guidelines and quality assurance procedures.

## Technologies

- Python
- OpenCV
- NumPy
- JSON
- Git and GitHub
